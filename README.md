# C-Guessing-the-number-and-alphabets-game

This is a Number and Alphabet Guessing Game developed using the C programming language.

This is my first-ever project, and I developed it to practice my C programming concepts and build my first complete game.

 **Features**

 1) Number guessing mode
 2) Alphabet guessing mode
 3) Four difficulty levels:
  - Easy
  - Medium
  - Hard
  - Expert
  4) Random number generation
  5) Multiple attempts
  6) Hints during the game
  7) Score calculation
  8) Time-based scoring
  9) Option to play again

**Hint System**

The game provides hints as the player continues making attempts:

 After 3 attempts → First hint
 After 8 attempts → Second hint
 After 12 attempts → Third hint

This gives the player additional help while still keeping the game challenging.
